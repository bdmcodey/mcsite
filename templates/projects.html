Enhancing MARC serials holdings with AI

An exploratory project (and the subject of an upcoming conference poster) applying AI to a stubborn cataloging problem: turning free-text serials holdings (human-written MARC 866 "textual holdings") into structured, machine-actionable 853/863 fields. I compared approaches, including asking an LLM to read the statements directly. The one I chose put AI into building the tool rather than running it: the Holdings Workbench, developed with an AI coding assistant, is a Python application that runs deterministically, with no model or API key involved. It groups a file's 866 statements into recurring patterns, has a cataloger confirm what each captured value means, and writes the matching 853/863 fields. Whatever it leaves out, it names, and a statement it cannot fully account for keeps its 866.
